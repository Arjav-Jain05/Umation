# 09. Quality, testing and evaluation

Contents: 1 Test layers · 2 Fixtures · 3 Unit tests per module · 4 Integration and smoke tests · 5 Acceptance numbers per milestone · 6 Quality checks on outputs · 7 Calibration and results log · 8 Logging · 9 Troubleshooting table · 10 Definition of done

## 1. Test layers

1. **Unit tests** (fast, no network, no GPU): pure functions with fixtures.
2. **Integration tests** (local ffmpeg/CPU only): stages against synthetic media.
3. **Smoke test** (`scripts/dev_smoke_test.py`): one real short CC/own video end to end, run manually by the user or the agent; needs network and Gemini key.
Tests never call the real Gemini or YouTube. Use a `FakeGeminiClient` returning canned JSON from `tests/fixtures/gemini/*.json` and a `FakeYtdlp` that returns saved `source_info` fixtures. `pytest -q` must pass offline.

## 2. Fixtures (`tests/fixtures/`)

- `sample_transcript.json`: 12 minutes of synthetic but realistic gaming-commentary sentences with timestamps, words and 6 planted good moments (hook + payoff), 3 planted bad ones (intro, sponsor, rambling) and 5 fillers.
- `source_info_cc.json`, `source_info_no_heatmap.json`, `source_info_live.json`, `source_info_blocked.json`.
- `heatmap_100.json`: 100 segments with 3 peaks aligned to planted moments.
- `synthetic.mp4`: generated by ffmpeg lavfi (`testsrc2` + `sine`, 60 s, 1920x1080, 30 fps) so no copyrighted media is stored: `ffmpeg -f lavfi -i testsrc2=size=1920x1080:rate=30 -f lavfi -i sine=frequency=440 -t 60 -pix_fmt yuv420p synthetic.mp4`.
- `synthetic_face.mp4`: same plus a drawn moving ellipse "face" is NOT reliable for MediaPipe; instead the face tests use a small CC0 face image pasted on a moving background (`scripts/make_fixtures.py` generates it from `assets/models/test_face.jpg`, downloaded by `download_models.py` from a CC0 source; skip those tests with a clear message if absent).
- `gemini/*.json`: canned nominate/judge/parts/director/locate/metadata/concept responses.

## 3. Unit tests (names are required; add more as needed)

M1:

- `test_nominate_validation.py`: invalid ids dropped, duration limits, merge duplicates.
- `test_refine.py`: hook trim, tail trim, padding, length-fit rule from 04 section 4 step 5, min duration.
- `test_signals.py`: heatmap normalisation, coarse-heatmap weight override, audio z-score on a synthetic loud burst, speech ratio.
- `test_blend.py`: weights, penalties, weak-hook cap, topical boost, missing heatmap renormalisation.
- `test_planner.py`: threshold, tiers, overlap and text dedupe, soft cap, zero-clip result, id assignment.
- `test_part_splitter.py`: validation of parts, durations 25-65 s, child ids.
- `test_risk.py`: every flag and level combination from 04 section 10; high risk cannot be tier A.
- `test_gemini_client.py`: rate limiter spacing, retry/backoff on 429, cache hit avoids a call, invalid JSON retried once.
- `test_api_jobs.py`: 422 without ack, 201 with, listing, cancel.
- `test_orchestrator_resume.py`: stage skipped when artifact exists and validates; corrupted artifact is recomputed.

M2:
- `test_cutter.py`: keep-interval maths, 25% cap, quiet vs loud gap rule, filler removal, filter script text for K intervals.
- `test_remap.py`: `remap()` on boundaries and removed regions.
- `test_layout_detect.py`: classification thresholds with synthetic face boxes (table-driven).
- `test_smoothing.py`: dead zone, velocity limit, face-lost behaviour.
- `test_captions.py`: chunking 2-4 words, ASS validity (parse back), colours in BGR, profanity mask, events monotonic.

M3:
- `test_edit_schema.py`: density rules, clamping, snapping to word starts, safe-zone enforcement.
- `test_director_fallback.py`: produces a valid edit list without Gemini.
- `test_locator_parse.py`: `parse_box` conversion and rejection rules.
- `test_effects.py`: each effect renders onto a blank 1080x1920 frame without exceptions, stays inside bounds, and draws something non-identical to the blank at mid-duration.

M4:
- `test_metadata.py`: validation, truncation, hashtag rules, fallback.
- `test_credit.py`: credit block fields and links; missing channel handling; never contains the strings "fair use" or "infringement".
- `test_thumbnail.py`: sizes 1280x720 and 1080x1920, text fits, anti-frame hash check (a frame passed in as a "thumbnail" must fail).
- `test_package.py`: folder layout, checklist failures produce `failed`.

## 4. Integration and smoke

`scripts/dev_smoke_test.py URL`: runs a job via the API against the local server, polls to completion, prints a table (stages, times, clips, tiers, risk) and runs the output checks in section 6 on every packaged clip. Exit code 1 on any failure. Documented in README.

## 5. Acceptance numbers (hard gates)

Reference machine: ASUS TUF F15, RTX 4060 8 GB, 16 GB RAM, on AC power.
- M1: 30-minute video: ingest + selection <= 8 minutes (Whisper large-v3 float16). `plan.json` validates. With `FakeGeminiClient` the planner is deterministic (same input -> same output).
- M2: per clip build <= 90 s; all section 6 checks pass on 100% of clips; 30-min source end-to-end <= 15 min.
- M3: compositor >= 20 fps; density rules hold on 10 sample clips; arrow hit rate >= 70% on a labelled set of 20 pointers (user or agent labels target boxes manually; hit = predicted box centre inside the labelled box).
- M4: 100% of packaged folders pass the 07 checklist; thumbnail anti-frame check passes on 100%.
- M5: UI works on 1366x768 and phone width; re-render of one clip <= 2 minutes; fast lane processes a 60-minute video in <= 12 minutes.

## 6. Output quality checks (`app/utils/qa.py`, used by final render, package and smoke test)

- Video: 1080x1920, h264, yuv420p, fps in [24,60], duration 12-95 s, size > 300 KB.
- Audio: aac, 48 kHz; integrated loudness -14 ±1 LUFS; true peak <= -1 dBTP.
- A/V sync: `abs(video_duration - audio_duration) <= 0.15`.
- No black frames > 0.3 s (ffmpeg `blackdetect=d=0.3:pix_th=0.10`).
- No freeze > 2 s unless the source is a still (`freezedetect`).
- Audio pop check at every cut (05 section 11).
- Captions: all inside safe zone (check ASS positions), no caption event longer than 2.5 s, no line > 20 characters.
- Text/blur sanity: a sharpness metric (variance of Laplacian on 5 sampled frames of the foreground region) must exceed a floor (start at 40; calibrate on the synthetic fixture; log values) to catch accidental heavy blur.

## 7. Calibration and results log

- Results: `POST /api/clips/.../results` stores views/likes per platform. UI shows a summary table on the home page (top clips by views).
- `scripts/calibrate_scoring.py`:
  1. Input: CSV of user ratings (clip id, rating 1-5) and/or the results table (views normalised by days since posting).
  2. Compute Spearman correlation between `final_score` and ratings/views, and between each signal (`llm`, `heat`, `audio`) and ratings/views.
  3. If at least 30 rated clips exist: grid-search weights `(llm, heat, audio)` in 0.05 steps (sum 1) maximising Spearman; propose new weights; **never overwrite `scoring.yaml` without writing a `.bak` and printing the diff**; apply only with `--apply`.
  4. Report per-tier hit rates ("share of A-tier clips rated >= 4").
- Warn in the output when fewer than 30 samples exist: "Too few samples; weights not changed."
- Honest rule: correlations below 0.2 are noise; say so in the report.

## 8. Logging

Format `%(asctime)s %(levelname)s %(name)s job=%(job)s clip=%(clip)s %(message)s` (use a `LoggerAdapter`). Log each stage start/end with duration, each Gemini call (prompt name, cached?, latency, tokens if known), each ffmpeg command (as a list, truncated to 500 chars) and its return code. ffmpeg stderr tail (last 20 lines) is logged on failure and stored in the error.

## 9. Troubleshooting table (also put a short version in README)

| Symptom | Likely cause | Action |
|---|---|---|
| `h264_nvenc` fails | old driver or wrong ffmpeg build | update driver; reinstall Gyan full build; fallback libx264 is automatic |
| Whisper `cudnn`/`cublas` DLL error | CUDA libs missing | 01 section 4 |
| Transcript has repeated text | hallucination loop | confirm `condition_on_previous_text=False`, VAD on |
| Captions missing in final video | `ass` filter path issue | run with relative paths and `fontsdir=fonts` |
| Captions wrong font | font file not found | check `assets/fonts` and `fontsdir` |
| Clips start with silence | refine hook trim not applied | check word timestamps; log trims |
| Face crop jitter | smoothing off | verify 05 section 6 parameters |
| Arrows point at wrong thing | locator low confidence slipped through | raise `min_confidence` to 0.7; keep verification pass |
| Gemini returns invalid JSON often | schema too loose | tighten schema; lower temperature |
| Job stuck at 0% | worker thread dead | check `app.log`; restart; job resumes |
| Download 403/extraction error | yt-dlp outdated | `scripts/update_ytdlp.py`; Deno installed |
| Disk filling | segments retained | Cleanup button; lower `max_height` |

## 10. Definition of done (any task)

Code written; types and ruff clean; tests added and passing (show output); docs updated (`PROGRESS.md`, `DECISIONS.md`); no TODOs left; behaviour verified against the reference file section that specifies it; the user told in plain language what changed.
